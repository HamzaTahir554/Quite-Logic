Quiet Logic — animated dark software studio demo

Files:
- index.html
- styles.css
- script.js
- assets/quietlogic-icon.png
- assets/quietlogic-wordmark.png

How to preview:
1. Extract the ZIP.
2. Double-click index.html, or open the folder with VS Code and use Live Server.
3. Replace the demo email/text/projects with your real content.

Included interactions:
- interactive network background
- animated orbits and floating UI cards
- scroll reveal animations
- 3D hover tilt cards
- magnetic CTA buttons
- cursor glow
- animated marquee
- parallax elements
- scroll progress bar
- responsive mobile navigation
- prefers-reduced-motion accessibility fallback
