# Portfolio presentation refinement

The existing Portfolio now has a concise Selected Work introduction, visitor-facing project counts, compact filter controls and intentionally centered one- and two-card grids. Regular cards are capped at 380px wide, with three desktop columns, two tablet columns and one mobile column. Titles use three-line clamping at 24–28px; framed logos use object-fit contain at 120–128px.

Category, Concept and Featured badges use existing project data. Regular cards preserve hover/focus disclosure, Space/Enter/Escape controls and first-tap reveal followed by second-tap or CTA navigation. Description previews use the existing short description when supplied, with a three-line limit. Reveal transitions use transforms and opacity, without animated blur. The existing logo failure placeholder remains available. Skeleton geometry follows the card logo, metadata and title layout.

The existing Admin Featured toggle now reaches the public presentation through two additive DTO fields: `featured` and `short_description`. The first featured record in the loaded results appears in a wider lead layout with an immediately visible preview and CTA. Other records retain Admin ordering. Database schemas, queries, filters, pagination, publication rules, uploads and routes are unchanged. Admin's private card preview also receives those existing fields.

Managed detail pages have an overview, readable narrative and optional technology sidebar. The existing description can use headings such as `Challenge:`, `Solution:` and `Outcome:` on their own lines, optionally followed by text on the same line. Markdown-style heading prefixes are also recognized. Sections are rendered only from supplied content; plain descriptions remain supported. Long prose is split at sentence boundaries. No unsupported outcomes, dates, screenshots or technologies are invented. Existing curated concepts retain their artwork and Atlas animations, with a clear Back to Portfolio link and technology direction from their existing data. Below-the-fold concept artwork now loads lazily through Next/Image, retaining its proportions. Long technology tags wrap within their containers.

Day clay surfaces, Night glass surfaces, the autonomous graph, the custom cursor and all unrelated application features remain. Theme switching uses identical geometry. No new dependencies or environment variables are required.

## Verification

Responsive presentation coverage includes 1440, 1280, 1024, 768, 425, 375 and 320px in Day and Night, long titles and descriptions, proportional logos, no horizontal overflow, single-project centering, keyboard navigation, first/second touch taps and Featured layouts. The existing regression suite checks loading/retry, missing images, managed publication and project details alongside authentication, reviews, SMTP, Calendly, themes and graph lifecycle.

Passed `npm run lint`, `npm run typecheck`, `npm run build`, formatting and whitespace checks. The completed `npm run test:admin` passed **293 integration assertions and 67 browser tests** using disposable MongoDB and a local SMTP sink. After the final lazy-image and long-tag wrapping changes, the production build and lint passed again, and **all seven portfolio tests passed** against that final build. The focused run disabled database access, mocked project-list responses and exercised the existing editorial routes; expected unavailable-service logs from unrelated database-backed footer requests occurred in that isolated run.

The integration runner now waits for one resolved Admin heading before visibility checks on streamed navigation. Its old compact-header assertion was updated to check the existing mobile booking drawer at widths up to 600px; the application header behavior was preserved.

Reviewed Day/Night card captures at 1440 and 320px, the Featured lead card and the 320px empty-state page. Screenshots are in [portfolio-refinement](portfolio-refinement/). Responsive and touch checks use Chromium emulation; physical-device testing was not performed. Unrelated screenshots generated by the broad suite were restored.
